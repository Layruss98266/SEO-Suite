A = last week's audit  →  B = today's audit
Result: URLs with score Δ, new issues, fixed issues

      

        A = older, B = newer
        Same site for accurate diff
        Green = improved, Red = regressed

    robots.txt Generator
    
    
    Build a valid robots.txt file from a form — no manual syntax needed
    
  
    
  
    
    
    🤖
    
    
    
      
    How to use
    
      
    Add one rule per user-agent (crawler). Each rule lets you allow or disallow specific path patterns. Add your sitemap URL at the bottom for Googlebot discovery, then copy the output to your site root at yourdomain.com/robots.txt.
    
      
    User-agent: *
Disallow: /admin/
Allow: /
Sitemap: https://example.com/sitemap.xml
    
      
    
        * applies to all bots
        Disallow: / blocks the whole site
        Always add Sitemap: line

    Hreflang Tag Generator
    
    
    Generate hreflang link tags for multilingual / multiregional pages
    
  
    
  
    
    
    🌐
    
    
    
      
    How to use
    
      
    Add one row per language/region variant of your page (e.g. en-US, en-GB, fr-FR). Each row maps a language code to the URL for that locale. Optionally add an x-default fallback for users whose language isn't explicitly listed. Copy the generated <link> tags into your <head>.
    
      
    <link rel="alternate" hreflang="en-US" href="https://example.com/en/">
    
      
    
        Add x-default for unlisted locales
        All variants must link each other
        Use BCP-47 codes: en-GB, fr-FR
