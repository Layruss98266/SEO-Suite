Features

One platform for
every technical SEO job.

Track crawl health, Core Web Vitals, structured markup, and Search Console insights. Get data directly from Google, PageSpeed, Moz, DataForSEO, and SerpAPI.

🕷️

Crawl & Routing Checks

Map out crawl paths, verify server response codes, trace redirect chains step-by-step, find broken links, inspect internal linking, check your canonical tags, and audit your robots.txt file.

📝

On-Page Optimization

Run thorough checks on your content: ensure titles and meta descriptions are the perfect length, inspect heading hierarchy, find missing alt text, check social preview tags, and measure response times.

🛡️

Security & SSL Auditing

Keep your site secure. Validate SSL certificates, check standard security headers like CSP and HSTS, detect mixed content issues, and verify email security settings (SPF, DMARC, MX).

⚡

Core Web Vitals & Speed

Check page loading speeds using the official Google PageSpeed API. Compare your Core Web Vitals on mobile and desktop side-by-side to find exactly what is slowing you down.

📊

Search Console Insights

Pull full search performance metrics directly from Google. Map your organic clicks, impressions, keyword rankings, and index errors without the usual limits or cutoffs.

🔗

Rankings & Domain Authority

Track where your pages rank for key search terms, monitor Google search features like featured snippets or FAQ boxes, and keep tabs on link authority with Moz and DataForSEO.

📑

Live Indexation Checks

See which of your pages are actually indexed in Google. Get answers straight from the Search Console API, or use our built-in browser to check live search results for external sites.

🧩

Schema & Sitemap Builders

Create perfectly formatted structured markup for your pages, including FAQ, Product, or Article schema. You can also generate robots.txt files, XML sitemaps, and hreflang tag groups.

🤖

Local AI SEO Assistant

Turn technical error logs into clear, actionable checklists and write search-optimized meta tags on the fly. Simply connect your own Groq API key to use Llama or Mistral safely.

📈

Run Comparisons & Exports

Export your audit data to HTML, Excel, CSV, or PDF. You can also track your progress over time by comparing the results of different runs side-by-side in your dashboard.

👥

Secure Accounts & Roles

Invite your team with secure multi-user access. Create admin roles, manage access to settings, and hide sensitive API keys so they stay completely safe.

🔔

Schedules & Notifications

Get updates sent straight to your email, Slack, or Microsoft Teams. Set up automated daily or weekly audits so you always know how your site is performing.
