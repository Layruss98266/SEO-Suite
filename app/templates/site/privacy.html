Privacy

Your data stays on your machine.

SEO Suite is self-hosted. We don't run a server you send data to — you run the server.

Last updated: 2026-06-19

What the tool stores

When you self-host SEO Suite, everything is written to the database and filesystem on your host. That includes:

  • Audit results, crawl logs, and exported reports
  • User accounts (email, hashed password, TOTP secrets, backup codes)
  • Login attempts and session records for security monitoring
  • API keys you enter for third-party services (Search Console, PageSpeed, Moz, SerpAPI, DataForSEO, Bing, Groq)
  • Site configuration and notification preferences

What leaves the host

Nothing, unless you ask for it. The app calls third-party APIs (Google, Moz, SerpAPI, etc.) only when you trigger a check that needs them, and only with the API keys you supply. Audit findings, account data, and reports never get sent to us.

Marketing site analytics

This marketing site does not run third-party analytics, ad pixels, or tracking scripts. The only external request from any public page is the GitHub stars badge from shields.io.

Cookies

The app sets a session cookie when you log in so you stay signed in across page loads. No tracking cookies.

Data retention & deletion

You own the data. Delete your account from inside the app to wipe your records, or drop the database and report directory at the OS level. The GDPR self-service export and one-click account deletion are built into the dashboard.

Contact

Privacy questions or a disclosure to report? Email security@example.com (replace with the address you publish for your deployment).
